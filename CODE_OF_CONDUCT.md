# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating you agree to uphold it.

Report unacceptable behavior privately via GitHub: open a security advisory at
https://github.com/cassioscabral/poecompanion-link/security/advisories/new and mark it as a
conduct report, or contact the maintainer @cassioscabral through their GitHub profile.
Maintainers will review and respond fairly and confidentially.
